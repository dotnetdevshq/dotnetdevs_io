# Asset sources

- `public/logo.png` is the unchanged 500 × 500 owner-supplied `NET devs` logo from `Downloads/NET devs - logo/1.png`. The header and sharing image use the full square with rounded corners; the favicon/apple touch icon also uses the original. The earlier `logo-lockup.png` crop is unused. The owner explicitly requested preserving the original square rather than cropping it.
- The fallback code mark and typographic newsletter artwork are original to this implementation. Violet is a proposed direction, not an established brand color.
- `public/social-card.png` is a 1200 × 630 original sharing graphic generated by `scripts/generate-assets.cjs` using the existing Next.js image renderer. Run `npm run assets` after changing branding, then rebuild. No image service or external font requests are needed.
- Platform SVGs are vendored from Simple Icons 11.15.0: `https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/{id}.svg`. License: `public/icons/LICENSE.md` (CC0). Platform marks belong to their respective owners; their use labels destinations and does not imply endorsement.
- Lucide icons use the existing `lucide-react` dependency (ISC license).
